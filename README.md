# Nuestro nonagésimo latido 💗

Página romántica para publicar gratis con GitHub Pages.

## Archivos
- `index.html`: escena de los cuatro objetos y la carta final.
- `style.css`: diseño vintage oscuro, animaciones y papel envejecido.
- `script.js`: interacciones y escritura progresiva de la carta.
- `assets/nuestra-foto.png`: fotografía que compartiste para el regalo.

## Publicar en GitHub Pages
1. Sube todos los archivos y la carpeta `assets` a un repositorio.
2. En GitHub entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.

La página no muestra instrucciones ni texto alrededor de los objetos. Cada reliquia ocupa el centro de la pantalla y el texto aparece al final, en una carta con estética de papel antiguo.
